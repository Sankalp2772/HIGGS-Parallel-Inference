# Benchmark results

Store raw repeated-run measurements in CSV format here. Preserve each run rather than keeping only averages. Suggested fields: implementation, dataset_rows, threads, processes, run_index, elapsed_seconds, correct_predictions, accuracy, average_probability, throughput_rows_per_second, timing_scope, host, OS, compiler_or_toolkit.

Derived speedup/efficiency tables should be generated from raw measurements and document the baseline used.
